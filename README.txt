KUN TARTIBI TREKERI — o‘rnatish (5 daqiqa)

Bu oddiy veb-ilova (PWA): server kerak emas, bepul, telefonga haqiqiy ilova kabi o‘rnatiladi va internetsiz ham ishlaydi.

1) Internetga joylash (bittasini tanla):
   a) Netlify: app.netlify.com/drop ga kir, shu papkani (kun-trekeri) sudrab tashla. Link beradi.
      Akkaunt ochib saqlab qo‘yish kerak bo‘lishi mumkin, aks holda sayt o‘chib ketadi.
   b) GitHub Pages (doimiy, bepul): yangi repo och, shu fayllarni yukla,
      Settings > Pages > Branch: main > Save. Link: https://<login>.github.io/<repo>/

2) Telefonda linkni och:
   Android (Chrome): ⋮ menyu > “Install app” / “Ilovani o‘rnatish”
   iPhone (faqat Safari): pastdagi Ulashish tugmasi > pastga aylantirib “Add to Home Screen” > Add.
   MUHIM: ma’lumot ikon orqali ochilgan ilovada alohida saqlanadi, shuning uchun o‘rnatgach faqat ikondan foydalan.

3) Ma’lumot shu telefonning o‘zida saqlanadi. “Tana” bo‘limidagi “Yuklab olish” tugmasi
   (iPhone’da Ulashish oynasi chiqadi: “Save to Files”) bilan ora-sira zaxira nusxa ol. Telefon almashsa “Tiklash” orqali qaytariladi.

Vaqtlarni o‘zgartirish: index.html ichidagi const T=[ ... ] ro‘yxatini tahrirla.
